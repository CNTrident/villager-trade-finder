## 1.9.4 更新

- 1.20～1.21.11 也支持带轮次的最终报价。全部 24 个支持版本的单人世界都会自动启用加速。
- 多人服务器可在服务端选装与客户端及游戏版本一致的 1.9.4 JAR。未提供带轮次报价的服务器仍可使用客户端兼容流程。
- 初始、后续和全部交易均在收到本轮所需报价后检查。后续和全部模式使用 VisibleTraders 提供的本轮完整后续报价。

## 下载与安装

[下载全部 24 个安装包的 ZIP](https://github.com/CNTrident/villager-trade-finder/releases/download/v1.9.4/all-24-installers-1.9.4.zip)

覆盖 1.20～1.21.11 的 19 个正式版本，以及 26.1、26.1.1、26.1.2、26.2、26.3。解压后选择与 Minecraft 版本一致的一份 JAR，替换客户端 `mods` 中的旧版。`-sources.jar` 用于浏览源码。

- 客户端需要对应的 Fabric Loader、Fabric API 和 Trade Cycling。多人服务器也需要 Trade Cycling。
- 后续和全部交易需要双端 VisibleTraders。1.20～1.20.4 的 VisibleTraders 0.0.4 需要 Java 21。
- 兼容版本、依赖和文件校验值见附件 `version-manifest.json` 和 `SHA256SUMS.txt`。

右键未锁定交易的职业村民，按 `C` 配置，按 `R` 启停。原有筛选配置可以继续使用。[完整验证记录](https://github.com/CNTrident/villager-trade-finder/blob/v1.9.4/VALIDATION.md)
