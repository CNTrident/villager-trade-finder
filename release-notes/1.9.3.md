## 1.9.3 更新

- 26.x 单人模式收到本轮最终报价后即可判断是否命中。多人可在对应游戏版本的服务端选装同一份 1.9.3 JAR 启用加速。
- 1.20～1.21.11 提供 1.9.3 客户端兼容构建，保留 50 毫秒报价稳定窗口。26.x 连接未启用加速的服务器时也走兼容流程。
- 初始、后续、全部交易均逐轮检查。后续与全部交易会等 VisibleTraders 的完整后续报价，只有未命中才开始下一轮。

## 下载与安装

[下载全部 24 个安装包的 ZIP](https://github.com/CNTrident/villager-trade-finder/releases/download/v1.9.3/all-24-installers-1.9.3.zip)

覆盖 1.20～1.21.11 的 19 个正式版本，以及 26.1、26.1.1、26.1.2、26.2、26.3。解压后选择与 Minecraft 版本完全一致的一份安装 JAR，替换客户端 `mods` 中的旧版。带 `-sources.jar` 后缀的是源码包。

- 客户端需要对应的 Fabric Loader、Fabric API 和 Trade Cycling。多人服务器也需要 Trade Cycling。
- 筛选后续或全部交易需要客户端和服务器安装对应版本的 VisibleTraders。
- 1.20～1.20.4 使用 Java 17，1.20.5～1.21.11 使用 Java 21，26.x 使用 Java 25。依赖和文件校验值见附件 `version-manifest.json` 和 `SHA256SUMS.txt`。

右键未锁定交易的职业村民，按 `C` 配置筛选条件，按 `R` 开始或停止。原有筛选配置可继续使用。

## 验证

24 个版本均通过构建及自动回归。26.3 在单人世界和本地 TCP 专用服务器中验证了命中停刷，单人后续交易的两条刷新路径各完整筛选 113 轮。[完整验证记录](https://github.com/CNTrident/villager-trade-finder/blob/v1.9.3/VALIDATION.md)
