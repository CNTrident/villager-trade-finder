Villager Trade Finder 1.8.0 补全版：增加 Minecraft **26.1、26.1.1** 安装包，完整覆盖 **1.20～1.21.11 的 19 个正式版本，以及 26.1、26.1.1、26.1.2、26.2**，共 23 个版本。原版 1.8.0 Release 继续保留。

功能与 1.8.0 一致：

- 各村民职业独立目标列表，中英文名称、ID 与分页自动补全。
- 多目标 AND/OR、ON/OFF/AUTO；支持初始、后续、全部交易范围。
- 附魔书、附魔装备的完整附魔集合和等级、价格条件；制箭师药水箭按具体药水类型匹配。
- 等待服务端交易数据后再判断和刷新；找到目标或手动停止时输出次数，每轮从零计数，上限 100000 次。

安装与使用：

1. 只安装一份与游戏版本完全对应的 JAR，放入客户端 `mods` 文件夹。`-sources.jar` 是源码，不可作为 Mod 安装。
2. 安装对应版本的 Fabric Loader、Fabric API 和 Trade Cycling；多人服务器也需要 Trade Cycling。
3. 26.1、26.1.1、26.1.2 使用支持该版本的 Trade Cycling 1.0.21 或兼容新版；需要未来交易时，客户端与服务器另装 VisibleTraders 2.4.x。26.2 对应 VisibleTraders 2.5.x。
4. 运行 Java：1.20～1.20.4 为 Java 17，1.20.5～1.21.11 为 Java 21，26.1～26.2 为 Java 25。
5. 打开尚未交易锁定的职业村民，按 C 编辑目标，R 开始或停止。预筛大师级药水箭等后续交易需要 VisibleTraders。
6. 1.20、1.20.3、1.21.2 暂未在 Modrinth 找到单独标注的 Trade Cycling 成品，需要核对官方前置兼容性，不能直接混装其他版本。

附件：

- 各版本可安装 JAR，以及单独标注 `-sources` 的非安装源码 JAR。
- `villager_trade_finder-1.8.0-all-installers.zip`：全部 23 个版本的安装包与说明，适合网盘分享；不包含源码 JAR 或前置 Mod。
- `version-manifest.json`：各版本依赖、源码目录和成品校验值；`SHA256SUMS.txt`：所有附件的 SHA-256。

已通过本地构建和自动回归检查；未完成逐版本游戏内实测。源码位于当前标签，26.x 的构建参数见 `mc26-matrix.json`，1.20～1.21.11 独立源码见 `backports/versions/`。
