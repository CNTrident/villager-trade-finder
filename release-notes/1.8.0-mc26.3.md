Villager Trade Finder 1.8.0 新增 **Minecraft Java Edition 26.3 + Fabric** 构建。本次同时提供包含此前版本的 24 版本安装包合集；此前 Release 和文件保留。

功能：

- 各村民职业独立目标，中英文名称、ID 与分页自动补全。
- 多目标 AND/OR、ON/OFF/AUTO；支持初始、后续、全部交易范围。
- 附魔书、附魔装备支持完整附魔集合、等级、原始价格筛选；制箭师药水箭可指定具体药水类型。
- 收到服务端新交易数据后再判断和刷新；命中或手动停止时显示本轮次数，每轮从零计数，上限 100000 次。

26.3 安装：

1. 使用 Java 25、Fabric Loader 0.19.3 或更新版本，并安装对应 26.3 的 Fabric API 与 Trade Cycling；本次构建使用 Fabric API 0.163.0+26.3、Trade Cycling 1.0.23+26.3。
2. 将 `villager_trade_finder-fabric-26.3-1.8.0.jar` 放入客户端 `mods` 目录。多人服务器也需要 Trade Cycling，本模组自身只需客户端安装。
3. 如需预筛后续/全部交易，客户端与服务器需另装支持 26.3 的 VisibleTraders 2.5.1 或兼容新版。
4. 打开尚未交易锁定的职业村民，按 C 编辑目标，R 开始或停止。

附件：

- 不带 `-sources` 的 JAR 是可安装 Mod；`-sources.jar` 是开发用源码，不能安装。
- `villager_trade_finder-1.8.0-all-24-installers.zip` 包含 1.20～1.21.11 的 19 个正式版本，以及 26.1、26.1.1、26.1.2、26.2、26.3。解压后只选对应游戏版本的一份 JAR；合集不含源码或前置 Mod。
- `version-manifest.json` 给出每版依赖、源码目录及文件校验值，`SHA256SUMS.txt` 可核对全部附件。
- 1.20、1.20.3、1.21.2 的 Trade Cycling 前置兼容性仍需核对，不可直接混装其他版本。

已通过本地构建和自动回归检查，未完成游戏内实测。26.x 源码与构建参数见当前标签下的根目录源码和 `mc26-matrix.json`，旧版本独立源码见 `backports/versions/`。
