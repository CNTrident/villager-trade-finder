修复给村民使用命名牌后，自动刷新与设置按钮消失、快捷键无法识别当前职业的问题。命名村民现在与普通村民使用相同的职业目标列表；原有配置继续可用。

- 完整接收本轮交易并判断目标后，再请求下一次刷新；命中即停止，不提前多刷一轮。后续交易的加载占位包不会触发续刷。
- 保留各职业独立目标、AND/OR、ON/OFF/AUTO、精确附魔集合、药水箭和原始绿宝石价格筛选；安全上限为 100 万次。
- 支持 1.20～1.21.11 的 19 个正式版，以及 26.1、26.1.1、26.1.2、26.2、26.3，共 24 个游戏版本，每版独立 JAR。

## 安装与使用

1. 选择与你的 Minecraft 版本完全匹配的一份安装 JAR，替换客户端 mods 中的旧版后重启。不要同时安装两个版本。
2. 客户端安装对应 Fabric API 和 Trade Cycling；多人服务器也需要 Trade Cycling。后续/全部交易筛选需客户端和服务器均安装对应版 VisibleTraders。
3. 右键尚未交易锁定的职业村民，按 C 配置目标、R 开始或停止；已命名村民使用相同操作。没有实际村民实体交互的虚拟、远程菜单不启用。
4. 1.20～1.20.4 使用 Java 17，1.20.5～1.21.11 使用 Java 21，26.x 使用 Java 25。Fabric Loader、API 和依赖详情见版本清单与仓库 README。

`all-24-installers-1.9.1.zip` 是全部安装包合集，解压后仅选一个匹配版本；带 `-sources.jar` 的文件仅供阅读源码，不能安装。GitHub 自动生成的 Source code 归档与项目提供的源码 JAR 不同。
